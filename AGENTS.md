# Repository instructions for coding agents

## README changes require owner approval

Treat every `README.md` in this repository, including translations, as
owner-controlled content.

- Do not edit a README unless the user explicitly requests a specific README
  change or approves a concrete proposed change in the current conversation.
- Before a broad rewrite, restructuring, change of audience or positioning,
  or substantial deletion, show the proposed text or diff separately and wait
  for explicit approval. Do not overwrite the README to prepare that proposal.
- Requests such as "clean up", "remove slop", "improve the docs", or "update
  the release" do not authorize a broad README rewrite. Propose the scope first.
- Apply only the approved changes. Preserve unrelated wording, sections and
  links. A request to change one section does not authorize rewriting the rest.
- Permission to commit, push, publish, or update packages does not grant
  permission to change README content. Earlier approval of a README edit does
  not authorize future rewrites.
- If approval is missing, continue other authorized work and leave the README
  unchanged. Do not automatically revert or restore its content either.
- Do not remove or weaken this approval rule without explicit user approval.

These instructions govern agent behavior; they are not a technical access
control or a substitute for repository review protections.
