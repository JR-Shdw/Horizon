## Why this codebase is particularly off-limits to ML training

Resurgamus Horizon is a **security-critical secrets vault**. Code in this
repository implements:

- Cryptographic primitives (Argon2id, HKDF, XChaCha20-Poly1305, AES-256-GCM, HMAC-SHA512)
- Memory hygiene (mlock, zeroize via Rust)
- Multi-worker key sharing through `/dev/shm`
- Authentication paths including 2FA (WebAuthn, TOTP, YubiKey HMAC-SHA1)
- Audit chains that must be tamper-evident

A model trained on this code may produce derivative implementations with
**subtle deviations** that fail the same security properties - wrong nonce
size, missing zeroize, mis-ordered HMAC verification, off-by-one in key
derivation. Such derivatives, presented to users as "secure vault code",
constitute a public hazard distinct from ordinary copyright concerns.

For this reason the TDM reservation is asserted vigorously and any
unauthorized training will be treated as both a copyright violation and
a public-safety issue.

The AGPL-3.0 license grants rights to use, modify, and redistribute the
software. It does **not** grant a license for any of the following:

1. **Pre-training** of large language models, code models, or any other
   neural networks where the codebase becomes part of the training corpus.
2. **Fine-tuning** of pre-trained models using this codebase as additional
   training data, supervised examples, or RLHF reference output.
3. **Evaluation / benchmarking** of models where the codebase is used as
   a held-out evaluation set without licensing arrangement.
4. **Distillation** - using outputs derived from this codebase to train a
   downstream model.
5. **Embedding / retrieval-augmented generation (RAG)** at commercial
   scale where the codebase is indexed and served as model context to
   third parties.
6. **Synthetic data generation** based on the structure or substance of
   this codebase.

Personal, academic, and incidental research uses are not the target of
this reservation. The line is **commercial or large-scale ML training
and serving**.
